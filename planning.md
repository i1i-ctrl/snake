# Planning

## Game Idea

We will create an online game in HTML.

The game will be Snake.

## How The Game Will Look

The game will have a specific game area on the screen. This area will be like a board or territory where the snake can move.

Inside the game area:

- The snake will be shown as a line of connected squares.
- The apple will be shown as a small red square or circle.
- The background will be simple and clear so it is easy to see the snake and apple.
- There can be a score shown above or near the game area.

## How The Game Will Behave

The player will control the snake using the arrow keys:

- Up arrow moves the snake up.
- Down arrow moves the snake down.
- Left arrow moves the snake left.
- Right arrow moves the snake right.

The snake will keep moving in the current direction until the player changes direction.

When the snake touches an apple:

- The apple disappears.
- The score goes up.
- The snake becomes longer.
- A new apple appears somewhere else in the game area.

The game ends if:

- The snake hits the wall of the game area.
- The snake crashes into its own body.

## Beginner-Friendly Build Plan

We will build the game step by step:

1. Create the HTML page.
2. Add the game area.
3. Draw the snake and apple.
4. Make the snake move.
5. Add arrow key controls.
6. Add apple eating.
7. Add score.
8. Add game over behavior.
